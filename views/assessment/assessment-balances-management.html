Import Instructions
  1. Download the template file to see the required format
  2. Fill in the balance data following the template structure
  3. The template uses the same columns and order as the exported CSV
  4. Required columns: Student ID, School Year, Period, Total Balance, Previous Balance, Current Balance, Advice to Pay
  5. As of Date accepts YYYY-MM-DD or MM/DD/YYYY
  6. Upload the CSV file
  7. The CSV imports when selected. Skipped rows and their reasons appear in the import summary.
Accepted format: CSV only. Maximum file size: 250 MB
